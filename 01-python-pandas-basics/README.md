
# Python & Pandas Basics

A beginner-level practical project documenting my learning and application of Python and Pandas as part of the Tech4Youth Data Analytics Programme.

## Project Objective

To develop practical skills in working with structured datasets using Python and Pandas, beginning with CSV data importation, DataFrame creation, data inspection, and manipulation.

## Skills Demonstrated

- Importing CSV datasets using `pd.read_csv()`
- Creating and working with Pandas DataFrames
- Inspecting and understanding structured datasets
- Basic data manipulation

## Skills to Explore

- Data cleaning and handling missing values
- Selecting and filtering rows and columns
- Descriptive statistics using `describe()`
- Grouping and aggregating data using `groupby()`
- Exploratory Data Analysis (EDA)
